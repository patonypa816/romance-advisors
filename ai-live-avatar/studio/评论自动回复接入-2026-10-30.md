# 评论筛选与历史 CloudBase 适配器

当前正式工作台使用百炼，配置见 [README](README.md)。`cloudbase_ai.py` 与 `sdk/` 是历史适配器和测试入口，不会因为启动工作台而自动调用。本文仅保留可复用的接入说明，不包含私人环境、收费探针结果、实播记录或凭据路径。

## 用户自配环境

`studio/data/cloudbase.json` 由操作者自行提供，不入 Git：

```json
{
  "env_id": "your-cloudbase-env",
  "region": "ap-shanghai",
  "model": "deepseek-v4.1-flash-1017",
  "credentials_file": "/path/to/your/private-credentials.csv"
}
```

`env_id` 默认空串，必须显式填写自有环境。格式是1–63字符的小写DNS标签：小写字母或数字，可在中间使用连字符。未配置时，历史适配器的 `configured()` 返回 false，调用被 `configuration_invalid` 拒绝；不会影响百炼默认流程。示例环境名与路径均为占位，不能直接用于调用。

腾讯云服务端密钥只从用户自有外部CSV读取，不放入源码、前端、命令行或诊断输出。建议凭据文件权限为 `0600`、所在私有目录为 `0700`。环境和模型是否可用、账号权限与费用应在操作者明确授权后核对，格式校验不证明云端资源存在。

公开SDK入口为 `@cloudbase/node-sdk` 的 `init({env,region,secretId,secretKey})` → `app.ai().createModel('cloudbase')` → `generateText`，见[官方Node SDK文档](https://docs.cloudbase.net/ai/model/nodejs-access)。helper只接受配置环境、模型和筛选／回复两类消息，经stdin接收必要数据；没有工具注册，`maxSteps:1`、`retries:0`、`keepalive:false`。

请求最多45秒、子进程输出最多256KiB；取消、超时会终止并回收本机helper，但不代表已提交云端的请求已撤销或免计费。收费请求失败不自动重发。

## 评论处理与验证

评论经过有界候选池、去重、过期、筛选及结构校验后进入唯一发送流程；当前事件触发筛选、礼物与欢迎统一编排等规则以README为准。评论是模型输入数据，没有工具权限，昵称和原文用文本渲染。来源代次、场次身份及取消保护阻止迟到结果进入新场。

可复现的合成检查包括：假模型与假渲染的Python回归、禁网替换transport的SDK检查、helper取消／超时／输出溢出回收、假SSE事件通过实际DyhubClient与候选池，以及虚构状态的界面检查。离线命令见README。这些检查不调用真实模型/TTS/Vidu，也不证明真实采集、语音、动作或OBS输出通过。

需现场验收时，先由操作者填写自有来源，再经明确授权开场，分别检查真实事件、筛选、声音、动作和停止结果。结束后回读云端结束状态，单独确认录像保存，再停止本任务的采集服务。工作台运行不授权自动公开推流或全天候托管。
