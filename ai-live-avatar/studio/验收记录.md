# 验收方法与边界

本发布副本不附私人实播记录、录像、运行路径或收费回执。以下是可复用的检查方法，不声明当前操作者环境已通过现场验收。

1. 用假模型、假渲染及合成评论运行离线测试，验证格式、队列、取消与唯一发送者保护。
2. 启动本机工作台，确认启动本身不创建收费云场；正常模式由OBS作为唯一接收者，预览模式由内嵌页替代。
3. 经操作者明确授权后再开收费场，分别核对RTC解码帧、音轨、实际声音、动作和OBS输出。播放器心跳或发送成功不能替代这些证据。
4. 结束后回读云端结束状态，并单独确认所需录像已保存；创建未知或结束未确认必须阻塞下一场。

离线命令：`.venv/bin/python -B -m unittest discover -s studio -p 'test_*.py'`。此检查不读取真实凭据、不调用收费服务；不代表真实平台采集、OBS音画或长时稳定性通过。
