# 产品范围

单人操作者在同一台 Mac 上控制数字人，OBS 作为唯一音画接收与录制/推流窗口。用户需要能看清当前是否开场、是否有人接收、弹幕如何处理以及云端是否结束；不需要第二套视频预览。

使用操作者自配角色、Qwen语音和整套阅读/直接接话策略。支持手动弹幕及 dyhub 真实评论；候选池先去重/过期，百炼 Qwen3.8-Flash 独立筛选后才进入回复队列。回复及同次语音时间戳后的动作编排也由同一指定模型通过百炼 OpenAI 兼容 HTTP 接口生成（非思考模式），已取消对 Codex Terra 存活的依赖。收费开场必须由用户显式点击；页面和服务启动均没有云端创建副作用。

成功标准：无视频控制台可操作，OBS 单接收者，状态真实回读，结束保护不降级，错误不会悄悄重建收费会话。离线验证、待机接入和收费实播分开记录。

手动弹幕联调补充：需要临时在工作台接收渲染流时，使用仅进程有效的 `--preview` 模式，优先在 Codex 侧边栏打开。该模式由工作台内嵌页替代 OBS 成为唯一接收者，沿用原有入会、心跳、停帧和结束保护；正常启动仍为 OBS 模式。

主持输入补充：操作者可发送一次安排、有限段数主讲话题或无语音的纯动作；观众评论不能改变输入身份或取得主持权限。主线在短轮发送边界与观众插话交替，不承诺逐字打断或已确认云端播完。换题和暂停撤销未开始发送的旧计划，失败不自动重播，已开始的一小轮收尾。回复历史、候选和筛选记录采用折叠限高列表，弹幕反馈留在回复区域。


数字人资产页补充（替代上文固定底图/试验入口的日常使用方式）：资产与底图、角色名称、人设、回复偏好按条目管理，云同步与上传显式触发。空闲选择开场，直播就绪且无待处理内容时可发送目标资产切换；发送成功后人工确认动态画面才更新角色并隔离旧上下文。顶部旧入口改为“重置当前形象”，图库无选择时保留历史type16-test配置兼容。声音源仅预留。预览模式切页保留原iframe小窗；OBS模式不新增接收者。发布副本不含私人资产清单；新上传、共用转场及白边问题需操作者受控验证。

互动补充：评论按事件唤醒筛选并保留1秒最小请求间隔。新增可编辑“礼物→动作／感谢词”规则与荣誉等级严格大于10的入场欢迎，忙时收集、轮间反馈，仍共用唯一发送器；原主持、评论、主讲的相对优先级保留。规则检查可在未开场时进行，实际排队须用户手动开场且就绪。礼物连击去重、欢迎批量与暂停／断线撤销均已离线验证；真实采集、动作画面与真实等级语义需现场单独验收。角色同音色四五句清唱尚未接入，仍需先验证声音。具体规则见README，验收方法见验收记录文档。
