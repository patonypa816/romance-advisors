# 恋爱军师团｜文档入口

版本：V1.2 本地首版。公开文档仅说明实现和可复现验证；个人试播记录不随仓库分发。

这里是《恋爱军师团》的现行文档目录。它与既有数字人项目、HELL INC. 游戏分别管理；当前已有仅监听本机的独立服务、SQLite数据保存和真实模型适配，可通过 DyHub 接收授权房间评论；可从工作台一键启动真实数字人自动联调。

文档用于帮助实现和验证，可以随用户决定与实际证据调整。下文的“已定”指本轮明确表达的产品方向，不代表永远不可修改；“建议默认”不等于用户已确认，也不应变成本地开工门槛。

## 已明确的当前方向

- 每期随机生成详细人物和处境；这是独立的娱乐情景剧，允许翻车，无跨期人物成长。一整期约七八分钟，包含多轮，时长需实测校准。
- Agent直接从本轮建议选最多4条，上屏选项就是投票选项；不设固定24条中间池，不补假选项。
- 程序统计并实时展示票数，投票期间男主不表倾向。最高票符合性格就采用；与性格冲突才掷一次隐藏骰子，约75%仍采用，约25%拒绝最高票后改选其他观众建议或自拟。
- 25%不是全部回合的自拟率；改选B的来源归B作者，真正自拟不挂观众作者。裁决和已合法确定的来源保存，刷新或修稿不重选。
- 男主可以质疑、吐槽，公开只说一次自然结论；改写保留观众创意，不擅自把可能翻车的主意改成稳妥话术。每正常完成轮实际发送一条男主消息、一条女生回复。
- 女生可自由创造剧情并决定亲密度增减，初始50、100成功、0失败；公开分数和实际变化。详细私有偏好仍不公开，观众从聊天与少量背景猜。
- 最强军师按加分次数÷采纳次数排序，同时设置狗头军师榜；整场累计，下一场重置。换期、刷新、重启都不清榜。
- 聊天持续追加；男主发送消息呈打字效果，不要求全文念出，只讲自然短反应；女生只有文字，可显示或念出被采用建议的作者昵称。
- Mac本地工作台保留纯文字游玩，也提供一键开始／停止数字人自动联调；用户只需手动发送模拟评论，征集、投票、数字人台词发送、换轮与换期自动衔接。真实采集和平台音画需要按自己的环境验证。

## 可先采用、仍需验证的默认

以下都保留为可调整建议，不能把整理文档当作用户批准了算法或参数。

| 编号 | 待选项 | 当前建议 | 什么时候需要明确 |
|---|---|---|---|
| D1 | 投票口令、一人几票、改票、平票、零票 | 单发当前选项编号 1～4，也接受「投1」「投 1」等写法。一人一票，截止前最后有效票生效；最高票平票抽一次；零票由男主选现有项或自拟 | 本地可受控演练，真实参与前核实身份和格式 |
| D2 | 输入过量与窗口时长 | 普通量整轮输入，文本预算到则提前关窗，极端积压有界降级 | 按实际模型容量和输入量调整 |
| D3 | 狗头榜算式与同率排序 | 减分次数÷有效采纳次数；同率先看采纳次数，同时展示样本数 | 首次玩法反馈时检查是否直观；无需独立排行榜系统 |
| D4 | 未完成结果及零变化 | 女生回复和评分有效后才算成绩；零变化计分母、不计加分或减分 | 保持技术失败与角色效果分开，见02结算规则 |
| D5 | 整期节奏与界面 | 七八分钟是目标，分数和台词共同表达终局；不硬改分数凑时长 | 真实模型连续游玩，观察耗时、早结束和久不结束的样例 |

旧Q1／Q2已由最新最高票规则取代。`α=0.8`、人设0／1／2档、普通加权择优和“25%必然自拟”均不用于当前实现。上述默认不要求逐条确认后才能开始原型，也不能写成用户已经批准。

## 当前实现与维护方式

- 产品、实现和验证分别维护；旧稿中的正常hold、女生no_reply、固定中间池、逐条展示屏障、复杂SAFE恢复不再带入。
- Downloads中的两份原稿保留；历史资料另存原样副本。原审查目录指向本入口，后续不再把审查长文当作实施规格。
- 新决定先改负责该规则的现行文档，再同步相关验证项和本页状态；不为每条小调整另建一份“最终版”。
- 合成测试覆盖核心规则、模型边界、事务回滚、状态增量、停止并发及故障清理。实际人物、剧情与音画效果需要在操作者自己的环境中验收。

游戏实现了零候选跳过编选、评论与票增量保存、状态增量更新、回执只读查询、模型连接复用、请求尺寸检查和本地耗时诊断。使用与故障处理见[工作台使用说明](docs/04-本地工作台使用.md)。

点击「开始自动联调」会使用操作者配置的资产启动收费数字人云会话。用户发送模拟评论，其余阶段自动推进，正常终局后自动开始下一期。单次联调跨期统一最多 20 分钟；点击「停止联调」或心跳持续失联后，停止发送并请求结束云会话。错误保留游戏记录并停止继续发送。纯文字模式仍可手动推进或仅自动推进本期。

工作台模式由预览页接收数字人。OBS 模式由 1080×1920 专用节目页接收，画面包含游戏组件、横标和人物。启动命令、OBS 浏览器源及直播伴侣的选择见[根目录启动说明](../README.md#3-先启动-studio-再启动游戏)。

正式短反应和等待互动支持逐句 TTS 情绪、可选 SSML 与同次生成的表情动作。正文和表演计划一起保存并冻结，共用一个发送器；收评论、计票和关窗继续进行，过时阶段话术丢弃。每轮正式口播后接固定无声低头输入，在 S 指令成功写出时公开男主消息。普通互动与游戏窗口独立：未回复评论可以参与普通互动，建议和计票仍遵守各自窗口；同作者后发闲聊不覆盖先前建议。

本公开树不包含个人试播场次、观众数据、云端资产绑定、账单或本机验收档案。离线测试入口见[开发与验证](docs/03-开发与验证.md)；发送回执、RTC 接收、视觉动作、录制及云端结束须分别核验。
