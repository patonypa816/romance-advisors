## 验收含义与限制

这说明 **M1 隔离模拟身份功能通过了当前自动化验收**，不是生产部署或整款游戏交付。

- Actions 使用临时 PostgreSQL 服务；验证了同一任务内 engine／应用重启持久化，没有验证跨 CI job 的数据库保留或长期运行宿主的数据保留。
- 没有部署生产服务、长期在线预览或阿里云资源；开发者需按 README 在选定宿主显式迁移并运行。
- 没有真实平台身份、抖音采集、真实玩家数据、模型调用、收费云场、数字人、RTC、OBS 或直播伴侣验收。
- P1 仍只有接口目标；M2–M6 尚未实现。没有职位／奖励／绩效修改，没有虚构经历。
- OS 锁是共享目录下的单宿主世界排他，不是跨机接管；迁机前必须确认旧实例停止。
- 长期数据库备份恢复、生产安全配置与真实部署仍需单独实施和验收。源码备份不等于数据库备份。
