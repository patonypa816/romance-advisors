## 观察到的真实问题
1. 时长目标未落实：上游脑只生成49字符，不是110–140字符。检查实际通用提示构造，原120字/1–2段句式已被替换，没有发现硬编码30字限制进入该调用；本次不能凭单例判定模型为什么忽略篇幅要求。
2. 每块4秒DRAIN真实存在：即使下一块已全部准备好，这个原收尾等待仍产生明显块间空档。不是网络或TTS慢，也不应算成表达时长。
3. 角色看“右侧评论区域”是模型给的目标，场景并未提供屏幕布局位置。不能当作实际看到了观众评论。
4. 第二段Q包含“回到镜头中央/恢复平静微笑”这类过渡措辞，当前输出与原调教要求“只写目标状态”并非完全一致。这是实际生成内容，应如实交给用户评估，而不是在报告中改掉。
